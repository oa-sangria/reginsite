USB RFID Reader Capture (keyboard-wedge, VID FFFF / PID 0035)

The USB reader shows up in Windows as a USB HID Keyboard: it types the tag ID and then presses Enter. Click the box below, then hold a tool tag on the reader. Each scan is decoded every common way (hex / decimal, normal / reversed byte order) and checked against the 34 seeded tags from DatabaseSeeder.php, so you can see at once whether the reader works, whether it reads the existing 13.56 MHz Mifare tags, and which output format it uses.
